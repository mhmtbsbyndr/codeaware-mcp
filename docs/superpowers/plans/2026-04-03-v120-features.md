### Task 3: Semantic Diff

**Files:**
- Create: `src/tools/semantic_diff.rs`
- Modify: `src/tools/mod.rs` — add `pub mod semantic_diff;`
- Modify: `src/tools/smart_edit.rs` — add `semantic_changes` field to `SmartEditResult`
- Test: `tests/test_semantic_diff.rs`

**What to build:**

1. `SemanticChange { change_type, symbol, from, to, breaking, affected_callers }` struct
2. `compute_semantic_diff(old_content, new_content, language) -> Vec<SemanticChange>`:
   - Extract symbols from old and new via `TreeSitterProvider::extract_symbols()`
   - Match by name: paired = same name in both, added = only in new, removed = only in old
   - For paired: compare `signature` → "signature_changed", compare `visibility` → "visibility_changed", compare line count → "body_changed"
   - `breaking = true` if signature_changed || visibility narrowed || symbol removed
3. Add `semantic_changes: Option<Vec<SemanticChange>>` to `SmartEditResult` (None by default, populated in server layer)
4. Tests: `test_no_changes`, `test_signature_change_detected`, `test_symbol_added`, `test_symbol_removed`, `test_visibility_change`, `test_body_only_change`, `test_breaking_flag`, `test_multiple_changes`

### Task 4: Smart Test Selector

**Files:**
- Create: `src/tools/test_selector.rs`
- Modify: `src/tools/mod.rs` — add `pub mod test_selector;`
- Modify: `src/tools/smart_edit.rs` — add `suggested_tests` field
- Test: `tests/test_test_selector.rs`

**What to build:**

1. `SelectedTest { test_file, test_name, reason }` struct
2. `TestSelection { selected_tests, command, coverage_estimate }` struct
3. `select_tests(edited_file, edited_symbols, project_root) -> TestSelection`:
   - Scan `tests/` directory for test files matching conventions (Rust: `test_*.rs`, `*_test.rs`; Python: `test_*.py`; TS: `*.test.ts`)
   - For each test file, read content and grep for: `use ...edited_module`, function name matches from `edited_symbols`
   - Build command: `cargo test <matching_test_names>` (Rust), `pytest <matching_files>` (Python)
   - If no matches, return full suite as fallback
4. Add `suggested_tests: Option<TestSelection>` to `SmartEditResult`
5. Tests: `test_finds_test_file_by_convention`, `test_matches_symbol_in_test`, `test_builds_cargo_test_command`, `test_fallback_to_full_suite`, `test_python_convention`
